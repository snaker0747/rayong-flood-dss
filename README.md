# ระบบเฝ้าระวังและติดตามน้ำจังหวัดระยอง (Rayong Smart Water Monitoring & DSS)

ระบบบริหารจัดการ เฝ้าระวัง ติดตาม และพยากรณ์สถานการณ์น้ำท่วมลุ่มน้ำระยองแบบบูรณาการข้อมูลน้ำระดับประเทศ (DSS - Decision Support System)

## 🌊 ปัจจัยสำคัญเฉพาะพื้นที่จังหวัดระยอง (Hydrological Crucial Factors)

1. **อ่างเก็บน้ำ 4 อ่างหลักและระบบผันน้ำ (Water Grid):**
   - **อ่างเก็บน้ำหนองปลาไหล** (163.7 ล้าน ลบ.ม.) - แหล่งน้ำหลักเชื่อมต่อคลองทับมา
   - **อ่างเก็บน้ำดอกกราย** (71.4 ล้าน ลบ.ม.) - รับน้ำจากปลวกแดง
   - **อ่างเก็บน้ำคลองใหญ่** (40.1 ล้าน ลบ.ม.)
   - **อ่างเก็บน้ำประแสร์** (295.0 ล้าน ลบ.ม.) - ครอบคลุมลุ่มน้ำประแสร์ อ.แกลง และมีท่อผันน้ำมายังคลองใหญ่
2. **จุดวิกฤตน้ำท่วมเขตเมืองระยอง:**
   - **คลองทับมา (ต.ทับมา)**: จุดคอขวดที่รับน้ำหลากจากตอนบนก่อนไหลลงแม่น้ำระยอง
   - **แม่น้ำระยอง**: ไหลผ่านเทศบาลนครระยอง ออกสู่อ่าวไทย
3. **อิทธิพลของน้ำทะเลหนุน (Tidal Backwater Effect):**
   - ปากน้ำระยองมีระดับน้ำทะเลหนุนสูงเป็นรอบวัน (Diurnal / Semi-diurnal Tide) หากตรงกับช่วงน้ำหลาก จะเกิดสภาวะน้ำดันระบายไม่ออก ต้องสั่งการประตูระบายน้ำและสถานีสูบน้ำทันที

## 🚀 เริ่มต้นทดสอบต้นแบบแดชบอร์ด (Quick Start Prototype)

คุณสามารถเปิดไฟล์ `prototype/index.html` บนเว็บเบราว์เซอร์ (Chrome, Edge) ได้ทันทีเพื่อทดสอบหน้าตาของระบบแดชบอร์ด, การแสดงผลแผนที่ GIS, กราฟพยากรณ์ล่วงหน้า 72 ชม. และเกจวัดปริมาณน้ำในอ่างเก็บน้ำ
